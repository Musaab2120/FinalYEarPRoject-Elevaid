# FinalYEarPRoject-Elevaid
This is my final year project application for Term 2510 in Multimedia University.

**Abstract**

Elevators play a crucial role in modern buildings by enabling efficient vertical mobility. However, traditional systems do not account for the needs of individuals with mobility challenges, such as elderly individuals and wheelchair users. This project aims to develop a priority-based elevator simulation that enhances accessibility through an intelligent scheduling system. 

The proposed simulation identifies priority users in real-time and dynamically adjusts elevator operations to ensure fair and efficient service. By integrating detection mechanisms and an optimized scheduling algorithm, the system prioritizes users requiring assistance while maintaining smooth operations for all passengers. A user-friendly interface allows for easy interaction with the simulation, enabling users to configure building settings and monitor elevator behavior. 

This project serves as a proof-of-concept for smart elevator systems, demonstrating how intelligent scheduling can improve accessibility without significantly impacting overall efficiency. Future improvements may include expanding the system to multi-elevator environments and refining detection methods to enhance accuracy and responsiveness. 

*How to run the project*
- download the zip folder
- extract it
- open the terminal or in command prompt run the command "python app.py"
- Ctrl+click on http://127.0.0.1:5000 to open it in your default browser
- configure the time settings and floor settings and run the simulations
- you can also check the time comparison on hoe efficient our priority system could be
